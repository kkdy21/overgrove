# T7. 서명 검증 프로그램 실행

> 상태: Accepted (Phase 2 게이트, 2026-11-05, #457에서 [security-review.md](../security-review.md) §2를 위협별로 나눔) · 관련: [security-review.md](../security-review.md) (범위·가정 §1, 최종 규칙 §3, 실험 기록 §4, 체크리스트 §5, S-05 근거 §6)

- **설명**: 서명 관련 log 포맷(`%G?` 등)을 쓰거나 로컬 `log.showSignature=true`가 있으면, `git log`와 `git show`가 `gpg.program`(또는 `gpg.ssh.program`)을 실행한다. 서명된 커밋이 하나라도 있으면 실행된다 (확인).
- **시나리오**: 악성 저장소가 가짜 서명 커밋 하나와 로컬 `gpg.program = <명령>`, `log.showSignature = true`를 둔다. 그래프를 여는 순간 실행된다.
- **대응**:
  - 공통 인자 `-c log.showSignature=false` (확인: 실행 안 됨)
  - 서명 포맷(`%G?`, `%GS`, `%GK`, `%GF`, `%GP`, `%GT`) 사용 금지. 카탈로그 리뷰와 정적 검사로 막는다.
  - 서명 표시 기능은 범위 밖이다.
- **잔여 위험**: 없음 (확인된 범위).
- **검증**:
  - SEC-T7-01 (악성 픽스처에서 graphPage, commitMeta, fileHistory → canary 없음)
  - SEC-T7-02 (소스에 `%G` 포맷 문자열이 없음을 검사)
- **상태**: 설계 완료
