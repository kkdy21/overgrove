# ADR-0006: 외부 의존성 0개를 유지한다

> 상태: Accepted · 날짜: 2026-11-05 · 관련: T17, HANDOFF §4

## 맥락

이 앱은 사용자의 로컬 저장소에서 프로세스를 실행하는 도구라서, 공급망이 오염되면 바로 코드 실행으로 이어진다 (T17). 소스 빌드 방식이므로 사용자가 클론해서 바로 빌드할 수 있어야 하고(G10), 패키지 해석 실패가 진입 장벽이 되면 안 된다.

## 결정

1. **앱과 테스트 타깃은 Apple SDK(Foundation, SwiftUI, AppKit, Observation, OSLog, XCTest/Swift Testing) 외의 패키지를 링크하지 않는다.** Swift Package Manager 의존성도 0개다.
2. **개발 도구도 툴체인 내장을 우선한다.** 포맷·린트는 `swift format`(ADR-0007), 시크릿 검사는 gitleaks를 쓴다. gitleaks는 로컬 hook과 CI에서만 실행하는 외부 바이너리이고 빌드 산출물에 들어가지 않는다. CI에서는 버전과 SHA-256 체크섬을 고정해서 받는다.
3. **GitHub Actions는 커밋 SHA로 고정**하고, Dependabot(`github-actions` 생태계)으로 갱신한다.
4. **예외는 ADR로만 허용한다.** 의존성을 추가하려면 새 ADR에 다음을 적는다.
   - 필요성
   - 대안 (직접 구현 비용)
   - 라이선스 호환성
   - 유지보수 상태
   - 버전 고정 방법

## 대안

| 대안 | 장점 | 단점 | 기각 이유 |
|---|---|---|---|
| libgit2 / SwiftGit2 | 프로세스 실행 비용이 없음 | 자체 Git 엔진 사용(N5 위반), C 라이브러리 공급망 | N5 |
| 파서·UI 유틸 패키지 사용 | 개발 속도 | 공급망 면적, 빌드 실패 위험 | 직접 구현 비용이 크지 않음 |
| SwiftLint·SwiftFormat | 규칙이 풍부함 | 별도 설치와 버전 관리 필요 | ADR-0007에서 기각 |

## 결과

- 클론 후 빌드 성공률이 높고, 공급망 면적이 최소가 된다.
- 파서, 그래프 레인 계산, diff 표시를 직접 구현해야 한다. 테스트로 품질을 보장한다.
- Dependabot은 Actions만 관리하게 된다.
